## Pin Assignments
```
Number     Pin Label     Description
1          VCC           5V/3.3V power input
2          GND           Ground
3          CS            LCD chip select signal, low level enable
4          RESET         LCD reset signal, low level reset
5          DC/RS         LCD register / data selection signal, high level: register, low level: data
6          SDI(MOSI)     SPI bus write data signal
7          SCK           SPI bus clock signal
8          LED           Backlight control, high level lighting, if not controlled, connect 3.3V always bright
9          SDO(MISO)     SPI bus read data signal, if you do not need to the read function, you can not connect it

(The following is the touch screen signal line wiring, if you do not need to touch function or the module itself
does not have touch function, you can not connect them)

10         T_CLK         Touch SPI bus clock signal
11         T_CS          Touch screen chip select signal, low level enable
12         T_DIN         Touch SPI bus input
13         T_DO          Touch SPI bus output
14         T_IRQ         Touch screen interrupt signal, low level when touch is detected

SD Card pins

1          SD_CS         SD SPI chip select
2          SD_MOSI       SD host write data
3          SD_MISO       SD host read data
4          SD_SCK        SD SPI clock
```
## Connect ILI9488 to ESP32 S3   

Most 3.5" ILI9488 SPI modules have a built-in 3.3V voltage regulator, meaning you can safely power the VCC pin with 5V or 3.3V. However, the logic signals (MOSI, SCK, DC, RST, CS) are strictly 3.3V. Fortunately, the ESP32-S3 natively outputs 3.3V logic, making them directly compatible.

Connecting the Touch (XPT2046) and SD Card modules alongside the ILI9488 display is very common, as most 3.5" modules have all three built onto the same PCB.
The key concept here is the Shared SPI Bus. The Display, Touch, and SD Card all share the same Clock (SCK), MOSI, and MISO lines. They are differentiated by their individual Chip Select (CS) pins. Only the device whose CS pin is pulled LOW will listen to or drive the shared bus.
Here is the complete guide to wiring and configuring all three.

**The ILI9488 Hardware Bug (Crucial Warning)**  
The SDO / MISO pin on an ILI9488 driver fails to release the SPI bus (it does not enter a high-impedance tri-state) even when the display's TFT_CS is high. If you wire the screen’s SDO / MISO pin directly to the same bus as the Touch and SD card, it will block the SD card and touch controller from talking to the ESP32-S3, causing them to fail.

**How to Correctly Wire the Shared SPI Bus**    
To bypass the hardware bug, disconnect the screen's MISO pin entirely (the screen doesn't need it to display graphics). Tie the Touch and SD card MISO pins together instead.

```
ILI9488 Pin     ESP32 S3 Pins      Description
VCC	            3.3V
GND	            Gnd
CS	            GPIO 9             Unique CS
RESET           GPIO 10
DC/RS           GPIO 14
SDI(MOSI)       GPIO 11            Shared MOSI pin
SCK             GPIO 12            Shared Clk pin
LED	            3.3V/ GPIO x       Backlight control, optional using PWM
SDO(MISO)       NC                 Do not connect
	
T_CLK           GPIO 12            Shared Clk pin
T_CS            GPIO 8             Unique CS
T_DIN           GPIO 11            Shared MOSI pin
T_DO            GPIO 13            Shared MISO pin
T_IRQ           GPIO y             Optional to use interrupt instead of software pulling
	
SD_CS           GPIO 7             Unique CS
SD_MOSI	        GPIO 11            Shared MOSI pin
SD_MISO	        GPIO 13            Shared MISO pin
SD_SCK	        GPIO 12            Shared Clk pin

```
